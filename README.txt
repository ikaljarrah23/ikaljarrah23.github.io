## Preview locally
Open `index.html` in a browser. Keep all files and folders in their current structure.

## Publish with GitHub Pages
1. Sign in to GitHub as `JarrahIK`.
2. Create a **public** repository named `JarrahIK.github.io` (the username portion must match your actual GitHub username exactly).
3. Upload the contents of this folder (not the containing folder itself), preserving the `assets` folder.
4. In the repository, open **Settings → Pages** and enable deployment from the `main` branch and `/ (root)`.
5. Wait for GitHub Pages to publish, then visit `https://JarrahIK.github.io/`.

The assignment says the GitHub username should match the JUST email username. You asked to keep `JarrahIK`, so this package does not change your account. Your site can still be hosted using your existing username; just be aware that this does not satisfy that particular username-matching note.

## Important note about the contact form
The assignment asks for JavaScript validation and a success alert. This form does both. It is a front-end demonstration and does not deliver messages to an inbox or store them on a server.
